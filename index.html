Hooks

Hooks são funções que permitem a você "ligar-se" aos recursos de state e ciclo de vida do React a partir de componentes funcionais. Eles permitem que você use o React sem classes, facilitando o compartilhamento de lógica entre componentes e tornando o código mais limpo e modular.
